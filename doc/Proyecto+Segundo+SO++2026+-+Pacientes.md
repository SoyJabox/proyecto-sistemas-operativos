# **_<u>Propuesta</u>_** 

Generar un conjunto de shell scripts que permita la gestión de socios de una mutualista, manipulando archivos de texto. 

El programa deberá permitir altas, bajas, modificaciones y consultas de socios, tomando en cuenta las siguientes directivas: 

   - Un socio debe tener al menos CI, nombre, apellido, teléfono, cuota social mensual, matrícula del médico de cabecera y fecha de ingreso) 

   - El médico debe estar presente en una lista de médicos que tendrá al menos  matrícula, nombre y apellido que será estática (es decir la hacen previamente y nunca la modifican, aunque el programa tiene que asumir que si ) 

   - La CI no se puede repetir para dos pacientes 

- Las consultas son: 

   - Nombre y apellido de todos los socios que son pacientes de un médico 

   - Cuota de un socio determinado 

   - Médico de un paciente 

   - Total mensual de ingreso de la mutualista por concepto de cuota social 

   - Al menos una consulta a elección del programador 

- El diseño de pantallas, menús y submenús es totalmente a elección del programador. Así como también el nombre que desee darle al shell-script principal. Este script deberá contener un menú con al menos las opciones para Alta, Baja, Modificación, Consulta y Salir (esta opción es la única que permite finalizar el programa) 

- Se deberá proporcionar una ayuda no interactiva desde la línea de comandos al estilo Linux. 

Ejemplo: bash Nombre_proyecto.sh --help deberá proporcionar una ayuda sencilla sobre el programa 

- Se deberá utilizar para guardar la información  ARCHIVOS DE TEXTO con campos separados por el delimitador “:”.
